# Naming

The merch store is named **OWUnion**. Use it in all new work: code, files, slugs, repositories, branches, labels, categories, and copy.

## Synonyms

These names refer to the same store. Older work keeps its original wording so changes stay visible over time. Do not rewrite it.

| Name | Where it appears | Status |
|---|---|---|
| OWUnion | New work | Current |
| OpenWaterUnion | Spec, PoC plan, decisions 002 and 003, session note | Long form used in older work, same store |
| Open Water X, OpenWaterX, openwaterx | Merchandise strategy, repo name `openwaterx-merch`, older notes | Retired, same store |

## Rules

1. New names use `OWUnion` (display) or `owunion` (slugs, paths, branches, repo names).
2. Do not edit existing documents to swap names. Add a note that the names are synonyms when a document needs it.
3. Version your docs when meaning changes, not to rename.
4. SKU prefix `OWU` already fits and stays.
